# Leaders College React Website

Responsive React + Vite landing page based on the supplied college courses poster.

## Run locally
1. Install Node.js (LTS).
2. Open this folder in a terminal.
3. Run `npm install`
4. Run `npm run dev`
5. Open the localhost URL printed by Vite.

Course details and phone numbers are based on the supplied poster. Please confirm details before publishing.
